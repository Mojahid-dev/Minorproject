## A workspace built for your files

| Collect | Understand | Stay organized |
| --- | --- | --- |
| Upload PDFs, Word and PowerPoint documents, text, Markdown, and images. | Extract text from text-based PDFs and view it alongside your resource. | Browse your library, search filenames, manage personal tasks, and remove resources. |

### Your own workspace

Sign in to access a personal dashboard and resource library. Resource records are associated with the signed-in account, and uploads are stored in private Vercel Blob storage.

### PDF text, ready to revisit

When a PDF contains selectable text, Zohra can extract and store that text for viewing in the library. Scanned PDFs without embedded text can still be uploaded, but their text cannot be extracted.

## Built with

**Next.js · React · TypeScript · Tailwind CSS · Better Auth · Prisma · PostgreSQL · Vercel Blob · PDF.js**

## Get started

The application lives in [`zohra-prjct/`](./zohra-prjct/). Follow its [README](./zohra-prjct/README.md) for prerequisites, local installation, environment variables, database setup, available commands, and Vercel deployment.

You will need Node.js 20.9 or later, pnpm, PostgreSQL, and a Vercel Blob store for file uploads.
